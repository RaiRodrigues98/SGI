FASE 10S - LIFECYCLE DE RODADAS
==================================

Alvo:
services\rodadas\lifecycle.py
└── _finalizar_rodada_atual()

Baseline:
3 HTTPException.

1) HTTP 404
"Rodada atual não encontrada."

2) HTTP 400
"Não é possível gerar uma próxima rodada a partir de uma rodada cancelada."

3) HTTP 400
"Não foi possível finalizar a rodada atual."

Mapeamento:
HTTP 400 -> BusinessRuleViolation
HTTP 404 -> NotFoundError

Regras preservadas:
- se a rodada não existe: erro 404;
- se a rodada está CANCELADA: erro 400;
- se já está FINALIZADA: retorna False (idempotência);
- caso contrário faz UPDATE para FINALIZADA;
- se rowcount == 0: erro 400;
- se atualizar corretamente: retorna True.

O status HTTP externo permanece exatamente o mesmo.

O instalador:
- exige exatamente 2x400 + 1x404;
- exige os três detalhes conhecidos;
- exige todos os raises dentro de _finalizar_rodada_atual;
- usa grafo cross-module com facades/reexports;
- rastreia callers em criacao/finalizacao e routers;
- bloqueia service intermediário que embrulhe Exception em HTTPException;
- adiciona/reutiliza handlers 400/404 nos routers;
- replica rollback/log existente;
- remove FastAPI do módulo;
- auto-restaura tudo em caso de falha.

Não altera:
- SQL;
- status FINALIZADA/CANCELADA;
- idempotência;
- rowcount;
- UoW;
- commit;
- conexão;
- services intermediários;
- rotas;
- respostas de sucesso.

Pré-requisito:
Fase 10R aplicada.

Aplicar:
python .\fase10s_excecoes_lifecycle_rodadas\aplicar_fase10s.py

1. Reinicie a API.
2. python tests_e2e\regressao_final_sgi.py
3. python .\fase10a_auditoria_excecoes_dominio\auditar_fase10a.py
