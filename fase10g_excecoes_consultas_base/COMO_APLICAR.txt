Por que o router precisa de análise transitiva?
-----------------------------------------------
Outras funções do mesmo service chamam essas funções:

exemplo:
consultar_contagem_atual()
    -> consultar_inventario()
    -> consultar_rodada_atual()
    -> consultar_localizacoes_inventario()

Então não basta adaptar apenas os endpoints que chamam
consultar_inventario diretamente.

O instalador:
1. monta grafo de chamadas entre funções top-level do service;
2. parte de:
   consultar_inventario
   consultar_rodada_atual
3. encontra todos os callers transitivos;
4. verifica quais dessas funções são importadas pelo router;
5. localiza os endpoints que as chamam;
6. adiciona NotFoundError -> HTTP 404 nesses endpoints.

Isso impede DomainError cair no except Exception e virar HTTP 500.

Migração parcial intencional
----------------------------

HTTPException em funções ainda não migradas.
