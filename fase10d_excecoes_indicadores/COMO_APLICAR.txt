FASE 10D - INDICADORES OPERACIONAIS
===================================

Escopo:
- services\indicadores_operacionais.py
- routers\indicadores.py

O service possui um único HTTPException:

HTTP 404
"Inventário ou rodada não encontrado."

Ele fica em:
_buscar_inventario_rodada()

Esse helper é utilizado pelos indicadores que precisam
do contexto Inventário + Rodada.

Migração:
HTTPException(404)
    ->
NotFoundError

No router:
NotFoundError
    ->
HTTPException(404)

Diferencial desta fase:
O instalador NÃO assume uma quantidade fixa de endpoints.

Ele usa AST para:
1. descobrir quais funções o router importa de
   services.indicadores_operacionais;
2. localizar quais endpoints realmente chamam essas funções;
3. localizar o except HTTPException de cada endpoint;
4. inserir NotFoundError -> HTTP 404 apenas nesses endpoints.

Portanto funciona com versões que tenham:
- acompanhamento;
- produtividade;
- localizações;
- outros endpoints do mesmo service,
desde que mantenham a estrutura segura esperada.

Consumidores:
Antes de alterar, o instalador exige que o único arquivo
de produção importando services.indicadores_operacionais seja:

routers\indicadores.py

Se houver outro consumidor:
ABORTA SEM ALTERAR.

Não altera:
- SQL
- get_connection/UoW
- cursor
- commit
- rollback
- cálculos
- KPIs
- respostas de sucesso
- rotas

Pré-requisitos:
- 10B aplicada
- 10C aplicada
- domain.exceptions.NotFoundError existente

Aplicar:
python .\fase10d_excecoes_indicadores\aplicar_fase10d.py

Depois:
1. Reinicie a API.
2. Rode:
python tests_e2e\regressao_final_sgi.py

3. Rode:
python .\fase10a_auditoria_excecoes_dominio\auditar_fase10a.py
