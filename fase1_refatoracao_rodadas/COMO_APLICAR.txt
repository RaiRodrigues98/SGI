COMO APLICAR
------------

1. Extraia esta pasta/pacote.

2. Copie a pasta fase1_refatoracao_rodadas para a RAIZ do SGI

3. Na raiz do SGI, execute apontando para o instalador, por exemplo:

   python .\fase1_refatoracao_rodadas\aplicar_fase1_rodadas.py

4. O instalador fará backup automático do arquivo atual.

5. Reinicie a API.

6. Execute:
