FASE 10L - ANALISE_RECONTAGEM OFICIAL
=====================================

Alvo:
services\analise_recontagem.py
└── analisar_recontagem_oficial()

Motivo:
Esse service participa do fluxo OFICIAL de R3+ e historicamente
é consumido tanto por análise direta quanto por services de rodadas
e encaminhamento gerencial.

Erros conhecidos em cópia preservada:
- 404 Inventário não encontrado.
- 400 Análise de recontagem disponível somente para inventário OFICIAL.
- 404 Rodada não encontrada para este inventário.
- 400 Esta análise é destinada às rodadas de recontagem R3+.
- 400 Esta rodada não possui itens de recontagem cadastrados.

Observação importante:
A auditoria 10A inicial apontou 5 HTTPException no arquivo atual,
mas uma cópia preservada na Library contém 4 em uma versão anterior.
Por isso o instalador usa o arquivo LOCAL REAL como autoridade.

Critérios para aplicar:
- todos os HTTPException do arquivo precisam estar dentro de
  analisar_recontagem_oficial;
- quantidade aceita: 4 ou 5;
- todos precisam ser status literal 400 ou 404;
- nenhum except HTTPException pode existir dentro do service;
- o único import FastAPI/Starlette deve ser HTTPException.

Mapeamento:
HTTP 400 -> BusinessRuleViolation
HTTP 404 -> NotFoundError

Grafo de consumidores:
O instalador indexa os módulos de produção e rastreia callers
transitivos até routers.

Ele bloqueia se:
- houver import do módulo em formato não resolvido;
- caller aparecer fora de services/routers;
- service intermediário fizer `except Exception` e gerar HTTPException;
- alguma fronteira HTTP não tiver padrão seguro de
  `except HTTPException: ... raise`.

Nos routers, o prefixo operacional do except HTTPException é replicado.
Isso preserva rollback/log antes da tradução da nova exceção.

Não altera:
- SQL
- lógica de conciliação Código + Lote
- regras R3+
- services intermediários
- commits
- abertura/fechamento de conexão
- rotas
- retornos de sucesso

Pré-requisito:
Fase 10K aplicada.

Aplicar:
python .\fase10l_excecoes_analise_recontagem\aplicar_fase10l.py

Depois:
1. Reinicie a API.
2. python tests_e2e\regressao_final_sgi.py
3. python .\fase10a_auditoria_excecoes_dominio\auditar_fase10a.py

Impacto esperado se o baseline local tiver 5 raises:
HTTP imports: -1
HTTPException raises: -5

Se tiver 4 raises:
HTTP imports: -1
HTTPException raises: -4

A nova auditoria 10A é a autoridade para definir a Fase 10M.
