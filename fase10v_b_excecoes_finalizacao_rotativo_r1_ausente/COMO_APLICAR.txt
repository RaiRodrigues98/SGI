FASE 10V-B - RODADAS / FINALIZAÇÃO ROTATIVO / R1 AUSENTE
================================================================

Alvo:
services\rodadas\finalizacao_rotativo.py
└── _encerrar_inventario_rotativo_apos_r2()

Erro:
HTTP 400
"Não foi possível localizar a R1 do inventário ROTATIVO."

Mapeamento:
HTTP 400 -> BusinessRuleViolation

RACIONAL
--------
A R2 não deveria existir sem uma R1 correspondente.
Nesse ponto do fluxo, a ausência da R1 representa estado
inconsistente do inventário, não um recurso solicitado pelo
cliente. Por isso mantemos o contrato externo HTTP 400.

PRÉ-REQUISITO
-------------
10V-A aplicada:
o erro:
"A R2 do inventário ROTATIVO ainda não foi concluída
operacionalmente..."
já deve estar como BusinessRuleViolation.

Se 10V-A não estiver aplicada:
- o instalador para antes de backup/mutação;
- nenhum arquivo é alterado.

PROTEÇÕES
---------
- altera somente 1 raise;
- total global do módulo deve cair exatamente em 1;
- SQL literal antes/depois deve ser idêntico;
- chamadas de negócio antes/depois devem ser idênticas;
- conexão/UoW/commit/rollback não podem mudar;
- consolidar_resultado_final_rotativo preservado;
- _finalizar_rodada_atual preservado;
- nenhum router é editado;
- FastAPI permanece enquanto existirem HTTPException.
