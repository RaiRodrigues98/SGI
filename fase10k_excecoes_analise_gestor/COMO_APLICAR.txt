FASE 10K - ANALISE_GESTOR
===========================

Alvo:
services\analise_gestor.py
└── analisar_inventario_gestor()

Baseline conhecido:
1) HTTP 404
   "Inventário não encontrado."

2) HTTP 400
   "Análise gerencial disponível somente para inventário OFICIAL."

3) HTTP 400
   "O inventário ainda não possui rodadas cadastradas."

Migração:
HTTP 404 -> NotFoundError
HTTP 400 -> BusinessRuleViolation

O service possui somente esses 3 HTTPException segundo a
auditoria 10A. Depois da migração, o import FastAPI é removido.

Por que esta fase é mais sofisticada?
-------------------------------------
analisar_inventario_gestor não é necessariamente consumida
apenas por routers\gestor.py.

O fluxo OFICIAL de criação de rodadas também historicamente
usa essa análise para validar decisões do gestor.

Por isso o instalador NÃO assume consumidores fixos.

Ele:
1. indexa todos os módulos Python de produção;
2. resolve imports `from módulo import função`;
3. monta grafo de chamadas intra/inter-módulo;
4. parte de:
   services.analise_gestor.analisar_inventario_gestor
5. encontra callers transitivos;
6. classifica:
   - services intermediários
   - routers finais
   - camadas inesperadas
7. bloqueia callers fora de services/routers;
8. bloqueia service intermediário que capture:
   except Exception
   e converta para HTTPException;
9. adapta todas as funções de router atingidas.

Preservação de rollback
-----------------------
Se um router atual faz:

except HTTPException:
    if uow:
        uow.rollback()
    raise

o novo handler é construído com o mesmo prefixo:

except BusinessRuleViolation as erro:
    if uow:
        uow.rollback()
    raise HTTPException(
        status_code=400,
        detail=str(erro)
    )

Assim a nova exceção não pula o rollback existente.

O mesmo ocorre para NotFoundError -> 404.

O instalador não altera:
- SQL
- services intermediários
- commits
- abertura/fechamento da conexão
- rotas
- retornos de sucesso
- regras do gestor
- regras de criação de rodadas

Pré-requisito:
Fase 10J aplicada.

Aplicar:
python .\fase10k_excecoes_analise_gestor\aplicar_fase10k.py

Se houver:
- import de módulo não resolvido;
- caller em camada inesperada;
- service intermediário que embrulhe Exception em HTTP;
- router sem padrão seguro de except HTTPException;

o instalador ABORTA ANTES DA ESCRITA.
