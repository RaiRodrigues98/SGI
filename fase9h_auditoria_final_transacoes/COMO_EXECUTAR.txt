FASE 9H - AUDITORIA FINAL DA CAMADA TRANSACIONAL
==================================================

Objetivo
--------
Esta fase NÃO altera o SGI.

Ela serve para provar que a Fase 9 pode ser encerrada.

O auditor procura, em todo o código Python de produção:

- get_connection()
- SqlServerUnitOfWork
- conn.commit()
- conn.rollback()
- uow.commit()
- uow.rollback()
- SQL de escrita em routers
- ownership transacional em services

Arquivos ignorados
------------------
- .venv
- backups
- __pycache__
- tests
- tests_e2e
- pastas dos instaladores fase1...fase9

Classificação
-------------
1. BLOQUEADOR

Router ainda usa get_connection() e:
- faz commit/rollback;
ou
- contém SQL de escrita.

Isso significa que ainda existe ownership transacional
legado no router.

2. LEITURA LEGADA PERMITIDA

Router usa get_connection(), mas:
- não faz commit;
- não faz rollback;
- não contém SQL de escrita.

Nesta Fase 9 isso não bloqueia o encerramento.

A futura padronização de queries/leitura pode tratar isso
se houver benefício arquitetural.

3. SERVICE TRANSACTION OWNER

Service possui conn.commit()/conn.rollback().

Isso não é automaticamente erro.

Exemplo já identificado:
- services/ciclos_rotativo.py
- services/rotativo_cobertura.py

Nesses fluxos o router usa UoW apenas como adaptador
de conexão e o service continua dono da transação.

4. TRANSAÇÃO EM CAMADA INESPERADA

Commit/rollback fora de router/service/infrastructure
é tratado como bloqueador e precisa ser analisado.

main.py
-------
Uso de get_connection() em endpoint diagnóstico/leitura
não bloqueia a Fase 9.

Se houver SQL de escrita no main.py, o auditor bloqueia.

Critério de aprovação
---------------------
A saída precisa terminar com:

RESULTADO FASE 9H: APROVADO

e depois:

FASE 9 - UNIT OF WORK / TRANSAÇÕES:
APTA PARA ENCERRAMENTO

Após isso, rode obrigatoriamente:

python tests_e2e\regressao_final_sgi.py

Critério final:
RESULTADO FINAL: APROVADO PARA HOMOLOGAÇÃO CONTROLADA

Somente com os dois resultados verdes consideraremos
formalmente a Fase 9 encerrada.

Executar
--------
Na raiz do SGI:

python .\fase9h_auditoria_final_transacoes\auditar_fase9h.py
