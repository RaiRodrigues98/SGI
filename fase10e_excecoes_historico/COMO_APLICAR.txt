FASE 10E - HISTÓRICO
=====================

Escopo:
- services\historico_itens.py
- services\historico_localizacoes.py
- services\historico_divergencias.py
- routers\historico.py

Motivo:
Os dois primeiros services têm exatamente um erro de validação HTTP 400:

historico_itens:
"O código do item é obrigatório."

historico_localizacoes:
"A localização é obrigatória."

Eles passam a usar:
BusinessRuleViolation

O router traduz:
BusinessRuleViolation -> HTTP 400

historico_divergencias:
A auditoria mostrou que o arquivo importa HTTPException,
mas não possui nenhum raise/except/uso adicional do símbolo.
A 10E remove somente esse import morto.

Não incluído:
services\historico_inventarios.py

Ele possui dois HTTPException segundo a 10A, mas será tratado
em fase separada depois de mapearmos exatamente status e mensagens.

Segurança:
- valida consumidores de historico_itens e historico_localizacoes;
- exige que ambos sejam consumidos somente por routers\historico.py;
- usa AST para encontrar os endpoints corretos;
- não assume linhas fixas;
- não assume quantidade total de endpoints do router;
- preserva get_connection/UoW;
- preserva cursor;
- preserva commit/rollback;
- auto-restore em qualquer falha.

Pré-requisito:
Fase 10D aplicada.

Aplicar:
python .\fase10e_excecoes_historico\aplicar_fase10e.py

Depois:
1. Reinicie a API.
2. Rode:
python tests_e2e\regressao_final_sgi.py

3. Rode:
python .\fase10a_auditoria_excecoes_dominio\auditar_fase10a.py
