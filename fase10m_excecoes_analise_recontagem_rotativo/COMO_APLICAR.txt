Por que criar exceção técnica separada?
---------------------------------------
O erro de coluna de quantidade indica que o schema do banco não
possui uma coluna esperada. O código interrompe a análise para
evitar produzir resultado de inventário incorreto.

Isso é uma falha técnica/configuração, não uma regra de estoque.

Não deve virar:
BusinessRuleViolation
DomainError
NotFoundError

Fronteira HTTP:
BusinessRuleViolation -> HTTP 400
NotFoundError -> HTTP 404
TechnicalConfigurationError -> HTTP 500

O detail atual é preservado exatamente.

Grafo de consumidores:
A análise ROTATIVO R2 pode ser chamada por services de rodadas/
finalização e por endpoints de análise.
